GitHub 上传材料说明

1. 本目录中的全部文件和子文件夹就是待上传材料；不必上传外层目录，也不要只上传 ZIP。
2. 保持 tasks、docs、reports 的目录结构，README.md、evaluate.py 与 PDF 位于仓库根目录。
3. README.md 是仓库首页；PDF、运行报告和来源说明已通过相对链接连接。
4. 发布到自己真实拥有的仓库后，再把实际仓库地址填入申请表。
5. 若选择公开仓库，任何人都可以查看内容。发布前自行确认愿意公开的范围。
6. 用退出登录的窗口核验公开链接；私有仓库需按平台允许的方式给审核人员访问权限。
7. 本材料未替你发布网站、创建仓库或上传文件；文件夹路径不是公开网址。
8. 材料是本次新建的 AI 辅助作品样例，个人复现和独立修改尚需据实记录，不保证审核通过。

随包 MANIFEST.sha256 记录文件哈希，便于核对下载完整性；它不是官方签名或第三方认证。
