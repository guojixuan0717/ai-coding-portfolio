# 训练记录稳定去重（t01_dedup）

本任务为新生成的 **AI 辅助作品集样例**，用于展示任务设计、实现和测试思路；示例与测试数据均为合成数据。它不代表任何人的既有任职经历、独立完成经历或官方认证。

## 场景与目标

训练数据常含有大小写、全角字符和首尾空白造成的重复记录。实现稳定去重函数，保留每个比较键第一次出现的完整记录，并保留这些首次出现记录的顺序。元数据不参与默认去重。

```python
def solve(
    records: list[dict],
    *,
    key_fields: tuple[str, ...] = ("prompt", "response"),
    normalize: bool = True,
) -> list[dict]:
    ...
```

运行环境：Python 3.10 或以上，仅使用标准库。

## 精确定义

1. `records` 必须是 `list`；每一项必须是 `dict`，且字典所有键都必须是字符串。
2. `key_fields` 必须是非空 `tuple`，元素必须是非空字符串且不能重复；字段顺序定义比较键各分量的顺序。默认字段是 `prompt` 和 `response`。
3. 每条记录都必须包含全部 `key_fields`，这些字段的值都必须是字符串。允许空字符串。其他字段的值可以是任意 Python 对象，不参与比较。
4. `normalize` 必须为真正的 `bool`，整数 `0`、`1` 不符合要求。
5. 若开启规范化，对每个比较字段依次执行 `unicodedata.normalize("NFKC", value)`、`.casefold()`、`.strip()`；若关闭，按原字符串比较。不得修改原记录中的字符串。内部空白不合并。
6. 比较键是各字段处理结果组成的元组，不能简单拼接，以免 `("ab", "c")` 与 `("a", "bc")` 冲突。
7. 保留第一次出现的记录以及其全部原始字段，忽略后续重复记录。返回一个新列表，其中每条保留记录为原字典的**浅拷贝**。函数自身不得修改输入列表、字典或嵌套对象。嵌套元数据与输入共享引用，不要求深拷贝。
8. 所有记录都必须检查，包括后续可能重复的记录；不允许静默跳过无效记录。

类型不符（列表/字典/字段类型、非布尔开关等）抛出 `TypeError`；空或重复的字段配置、缺失必需字段抛出 `ValueError`。异常消息和多项同时无效时的检查先后顺序不评分。

## 示例

```python
records = [
    {"prompt": " Ａ ", "response": "Straße", "source": "first"},
    {"prompt": "a", "response": "STRASSE", "source": "second"},
    {"prompt": "a", "response": "different", "source": "third"},
]
solve(records)
# [
#   {"prompt": " Ａ ", "response": "Straße", "source": "first"},
#   {"prompt": "a", "response": "different", "source": "third"},
# ]
solve(records, normalize=False)
# 三条都保留；仅完全相同的原始比较键才重复。
```

```python
solve(
    [{"id": " X ", "text": "a"}, {"id": "x", "text": "b"}],
    key_fields=("id",),
)
# [{"id": " X ", "text": "a"}]
```

## 边界与规模

空输入返回新空列表；全空白字段规范化后可以与空字符串重复；中文和符号不应被随意删除；重复记录的附加元数据可以不同。关闭规范化时，不做大小写转换、Unicode 转换或空白裁剪。返回结果的顶层字段可独立修改，嵌套元数据仍按浅拷贝语义共享。

设输入字典总条目数为 `M`、所选字符串的总长度为 `L`、输出字典总条目数为 `R`，合理实现的期望时间为 `O(M + L + R)`；哈希表操作采用平均常数时间假设。辅助空间由唯一比较键的总字符数及结果浅拷贝决定，最坏为 `O(L + R)`。规范化使用当前 Python 自带的 Unicode 数据库；本样例没有跨 Unicode 数据库版本的固定字节级结果承诺。
