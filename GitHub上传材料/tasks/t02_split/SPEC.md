# 任务 02：确定性且不泄漏的按组切分

## 背景与目标

同一来源的多条样本如果同时进入训练集与验证集，可能造成信息泄漏。请实现一个按 `group` 整组切分的函数。切分应能复现，不能随着输入行的排列改变组的归属。

仅使用 Python 3.10 及以上版本的标准库，无需联网或安装依赖。

```python
def solve(records, validation_fraction, seed=0):
    ...
```

## 输入与校验

- `records` 必须是 `list`；每一项必须是 `dict`。不接受元组、生成器等容器。
- 每条记录必须有 `group` 键，值为非空 `str`；其他字段及嵌套数据不参与分组。允许重复记录，也允许同一字典对象出现多次。
- 组名精确区分大小写和 Unicode 内容，不做去空格或字符归一化。因此 `"Group A"`、`"group a"`、`" "` 是三个合法且不同的组；`""` 非法。
- `validation_fraction` 必须是 `int` 或 `float`，排除 `bool`；必须有限且在闭区间 `[0, 1]` 内。
- `seed` 必须是 `int`，排除 `bool`；允许负数。
- 容器类型、记录类型、比例类型或种子类型错误时抛出 `TypeError`。组缺失、组不是非空字符串、比例越界或非有限值时抛出 `ValueError`。
- 即使输入为空、比例为 0 或 1，也必须完成适用的输入校验。不要求规定多个输入同时错误时的报错先后顺序。

## 唯一确定的算法约定

1. 取不同的组名，设组数为 `g`。
2. 将比例解释为它的十进制字符串表示对应的精确有理数，即 `Fraction(str(validation_fraction))`。验证组数为 `k = floor(g × fraction + 0.5)`，恰好一半时向上取整；不要使用 Python 的银行家舍入 `round()`。
3. 对每个组名 `group` 生成哈希输入：

   ```python
   json.dumps([seed, group], ensure_ascii=True, separators=(",", ":")).encode("ascii")
   ```

   计算其 SHA-256 摘要，按摘要字节的升序排列不同的组。若摘要相同，以 Python 字符串比较的组名升序作为次关键字。
4. 排名前 `k` 的组全部进入验证集，其余组全部进入训练集。
5. 返回恰好包含 `"train"`、`"validation"` 两个键的新字典，两个值是互不相同的新列表。每个列表中按原输入顺序保留记录，直接保留原字典对象；不要深复制、修改、丢弃或去重记录。

比例控制的是**组数**，不是记录数。组大小不同可能导致验证记录的占比和输入比例相差很大；本题不额外保证两侧非空。

## 例子

```python
records = [{"group": g} for g in "abcdef"]
solve(records, 0.5)
# {
#   "train": [{"group": "a"}, {"group": "d"}, {"group": "f"}],
#   "validation": [{"group": "b"}, {"group": "c"}, {"group": "e"}]
# }
```

种子为 0 时这六个组的完整排名为 `e, b, c, a, f, d`；返回列表仍保持输入行顺序。种子为 7 时完整排名为 `d, e, c, b, f, a`，所以相同比例的验证组为 `c, d, e`。

```python
solve([{"group": "a"}, {"group": "b"}, {"group": "b"}, {"group": "c"}], 1 / 3)
# {"train": [{"group": "a"}, {"group": "c"}],
#  "validation": [{"group": "b"}, {"group": "b"}]}

solve([{"group": "only"}, {"group": "only"}], 0.5)
# {"train": [], "validation": [{"group": "only"}, {"group": "only"}]}

solve([], 0.5)
# {"train": [], "validation": []}
```

第二例只有一个组，`floor(1 × 0.5 + 0.5) = 1`，所以整组进入验证集。比例为 0 时全部进入训练集，为 1 时全部进入验证集。

## 复杂度与边界

设输入行数为 `n`、不同组数为 `g`、所有不同组哈希输入的总长度为 `L`。预期时间复杂度为 `O(n + L + g log g)`，额外空间为 `O(n + g + L)` 上界；字符串比较及编码成本按输入文本规模计。可只保存摘要及组名，减少额外文本副本。

测试覆盖确定的 ASCII/Unicode 排名、大小写与空格、不同组大小、半数舍入、十进制舍入边界、零/全量比例、空输入、对象与顺序保留、重复记录、输入置换、不同种子以及非法参数。

本题只保证按给定组标识隔离样本。它不检查组标识是否准确，也不保证标签分层、时间先后、数据分布平衡、隐私保护或实际模型评估质量。公开测试与三个错误实现并不穷尽所有可能缺陷；本地满分不能推导出任何平台准入结果。
